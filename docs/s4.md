# S4 — Opening Range Breakout

Data aktualizacji: `2026-04-28`

## Cel strategii

`S4` jest drugim, świadomie odmiennym archetypem względem `S1C`.

Ma łapać:
- więcej trade'ów,
- szybsze wejścia intraday,
- breakout `NY opening range`,
- styl `breakout -> retest / hybrid continuation`,
- niższy `win rate` niż `S1C`, ale osobny silnik okazji.

## Jak działa

### Kontekst

Strategia działa tylko, gdy:
- `A1`: trwa okno `NY`,
- `A2`: kierunek HTF jest zgodny,
- `A5`: rynek ma wystarczający trend / ADX.

Nie wymaga sweepa jak `S1`.

### Setup

`S4` buduje pierwsze `30 min` sesji NY jako `opening range`:
- świeca `13:00 UTC`
- świeca `13:15 UTC`

Z tego wyznaczane są:
- `opening_range_high`
- `opening_range_low`
- `opening_range_mid`

Sygnał pojawia się, gdy:
- cena wybija `range_high` dla longa albo `range_low` dla shorta,
- jest potwierdzenie `price action trigger (C7)`,
- są dodatkowe potwierdzenia z wolumenu / VWAP / OBV.

### Wejście

Aktualna wersja nie goni już breakouta czystym marketem.

Tryby:
- `MARKET` dla słabszego setupu
- `HYBRID` dla lepszego setupu

W `HYBRID` wejście jest blendem:
- `45% current price`
- `55% breakout level`

To ma ograniczać pogoń za wybiciem i poprawiać RR.

### Stop loss

`SL` jest liczony względem:
- `opening_range_mid`,
- ewentualnie `opening_range_low/high`,
- z niewielkim buforem ATR.

To daje ciaśniejszy, bardziej scalpingowy profil niż `S1C`.

### TP / time-kill

Aktualny profil:
- `TP1 = 1.0R`
- `TP2 = 2.4R`
- ratio: `35% / 25% / 40%`

`time-kill`:
- `1.5h`
- minimalny progres: `0.15R`

## Co jest dobre

- Strategia jest naprawdę różna od `S1C`.
- Ma własny archetyp wejścia.
- Generuje dużo więcej trade'ów niż `S1C`.
- Po poprawce infrastruktury backtest realnie ją widzi.
- Ostatnia iteracja poprawiła `PnL` z `-3.50` do `-1.69`.

## Co jest złe

- Nadal ma ujemne `expectancy`.
- `TIME_KILL` jest częstym powodem zamknięcia stratnego trade'u.
- Średnia wygrana nadal nie kompensuje średniej straty.
- `SOL` i `BNB` generują ruch, ale nie dają jeszcze jakości.
- To wciąż nie jest strategia gotowa do live auto-execution.

## Najważniejsze wnioski

`S4` odpowiedziała na problem "potrzebujemy więcej trade'ów", ale jeszcze nie odpowiedziała na problem "potrzebujemy dodatniego PnL".

To znaczy:
- jako archetyp jest wartościowa,
- jako edge jest jeszcze niedokończona.
